(constant) carte :Array.<Carta>

Dataset completo delle 50 carte del gioco. Ogni carta rappresenta una situazione sfortunata a tema videogiochi, con indice di sfortuna crescente da 1 (banale) a 99 (catastrofico). Gli indici sono tutti univoci, con differenza minima di 2 tra ogni carta.

posizioneCorretta(hand, nuovaCarta, posizioneScelta) → {boolean}

Verifica se la posizione scelta dal giocatore è corretta rispetto all'indice della carta. Gestisce tre casi distinti:

  • Posizione 0: la carta deve avere indice minore di tutte le carte in mano
  • Posizione uguale alla lunghezza della mano: la carta deve avere indice maggiore di tutte
  • Posizione intermedia: la carta deve avere indice compreso tra la carta a sinistra e quella a destra
Parameters:
Name Type Description
hand Array.<Carta>

Array delle carte in mano ordinate per indice crescente
nuovaCarta Carta

La carta da posizionare nel mazzo tra quelle gia possedute
posizioneScelta number

La posizione scelta dal giocatore (0 = prima di tutto)
